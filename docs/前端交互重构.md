# 前端交互重构

本次目标：让两位家庭成员打开 App 后知道当前状态、下一步做什么，以及操作完成后去哪里。

## 信息结构

```
今天：原版月亮打卡主卡 → 待确认（有才显示）→ 最近一次 → 双人/个人本周分值 → 本周概览 → 一起积攒好梦
早睡：本周记录 / 待确认 / 周报
菜价：查价格 / 记一笔 / 历史记录
家庭：成员 / 共同规则 / 复盘 / 数据与连接
```

首页恢复原版布局、插画和图标。记录当前时间可以一天操作多次，以服务器最后一次记录的时间为准；只在请求执行中防止连点。凌晨归属遵循家庭时区与截止时间。打卡卡片下仅保留待自己确认的补卡、时间修改和豁免申请，没有时整块隐藏；不显示漏打卡或复盘提醒。双人分数、个人分值、四项统计和“一起积攒好梦”按原版顺序展示。

记录页先选日期再操作；待确认作为独立视图，由首页待办直达。补卡与豁免共享日期上下文，但操作后果单独说明。保存失败保留编辑内容，成功后才关闭。

菜价保留独立二级录入页；商品、店铺、金额与单位在同一张表单填写，可选信息折叠。首页不放菜价录入入口。连续录入保留店铺。草稿按服务器、家庭和编辑记录隔离，返回后可恢复。搜索服务于查询，也能把新商品名称带入录入流程。

页面用 URL hash 表示当前位置，支持浏览器及 Android 返回。二级页回到上级，底部四个入口稳定存在。

## 视觉约束

沿用已有夜间蓝色语言，把设计改动用于层级和操作关系：背景 #EDF2F8、纸面 #FFFFFF、正文 #253752、辅助 #63738B、行动 #486AA2、睡前提醒 #F5D995。中文使用 PingFang SC / Microsoft YaHei，数字使用 Avenir Next；标题 24–30px，正文 14–16px，辅助文字不少于 12px。

移动端优先、内容左对齐；主操作与当前状态组成一个整体。日期构成可点选的周历，家庭成员构成状态列表，规则构成分组菜单。避免所有内容都使用等权卡片。桌面保持适合两人日常使用的阅读宽度。

## 验证

覆盖跨午夜与周边界、已打卡/豁免/待确认状态、提交失败重试、菜价二级表单与草稿恢复、二级返回和窄屏布局；运行现有测试与生产构建。业务计分规则和后端接口保持现有语义。

## 首轮验证结果

- `npm --prefix mobile run build`：通过。
- `npm --prefix mobile test`：14 项通过，其中新增跨午夜、家庭时区、周/月/年边界和重复打卡状态测试。
- Chrome + 本机临时后端：通过真实打卡与完成状态、审批、补卡失败重试、两步录入返回不误提交、跨页草稿恢复、现场比价带入、连续录入、编辑/删除/撤销、离线缓存及重新联网自动刷新。
- 规则编辑期间触发家庭刷新：未保存输入保持不变。
- 320、390、768、1280px 下四个主页面无横向溢出；已检查手机截图。
- Android 实机返回键与软键盘尚未验证；本轮未生成发布包。

可复用浏览器验证脚本：`mobile/scripts/verify-interactions.mjs`。测试家庭数据与正式数据隔离。

## 首页融合调整

按反馈恢复原版问候、月亮插画和“一起积攒好梦”，结合本轮新增的已打卡状态、待确认、按日期进入记录和积分直达周报。菜价保留二级页面，去掉表单内的“下一步”，首页移除菜价快捷入口。分数等级与周报共用展示逻辑，图标直接复用项目原有 SVG。

本次调整已通过生产构建和 14 项现有测试，并在本地演示家庭中检查首页分数、好梦图标周历、进度条与菜价二级表单。

## 首页恢复原版（最新反馈）

恢复原版首页标题、问候、打卡卡片、最近一次记录、分数与好梦模块；保留四个主导航。移除打卡成功后将按钮替换为查看记录的限制，同一天可继续记录此刻。待确认提示移到主卡片下面，无待自己确认申请时隐藏。

验证：14 项前端测试及生产构建通过；本地演示家庭原有 16:46 打卡再次记录后更新为 17:15，按钮继续可用，无待确认事项时不显示提醒。

## 首页细节与记录周历

首页沿用原版结构，打卡卡片仅保留凌晨归属提示，多次记录的功能保持不变；待确认区按补卡、时间修改、豁免显示实际数量。本周记录复用好梦模块的月亮与打卡 SVG，选中日期用浅蓝底和外框区分，个人待确认日期用暖色圆点标记，保留日期切换与记录详情。

本地演示待确认数据可运行 `node mobile/scripts/seed-approval-demo.mjs` 生成。脚本只允许回环地址，并校验演示家庭和阿辰账号，通过正常 API 创建本周已到日期的两笔补卡、一笔豁免；已有记录或申请跳过。当前已生成 9 月 13、14 日补卡与 15 日豁免，保留待确认状态供调试。

本轮 14 项前端测试与生产构建通过；已在本地预览检查首页、待确认列表和图标周历。

## 本周概览紧凑整合

按最新反馈，将首页分数、统计、好梦三个区块合为一张“一起积攒好梦”卡片。顶部展示双人本周总分、等级及家庭完成度；成员表并列展示每人的本周分值、打卡天数、平均入睡和罚金；底部保留原有月亮与打卡周历。减少重复分数、重复完成度和卡片留白，增加另一位成员的详细统计。个人分值位于标有“我”的成员行。

前端 14 项测试与生产构建通过；本地预览已检查 320px 窄屏，页面和统计单元格均无横向溢出。

## 早睡页豁免入口

将底部折叠的本月豁免额度移至本周记录顶部，以紧凑卡片常显双方剩余、已用及待确认次数。卡片中的申请入口跟随周历选中的日期，先打开独立豁免说明弹层，再提交。未来日期、已豁免和额度用完时禁用；已有待确认申请时跳转申请列表。同步收紧日期标题与成员记录行的间距。

## 周历最终选中样式

最终采用方案 1：保留“星期—图标—日期”三层结构，默认图标与首页共用样式；选中整列使用淡蓝底（#e0e9f6）、10px 圆角和加深文字，无边框、外圈或短线。已打卡继续为蓝底白勾，未打卡继续为虚线月亮，待确认以暖色圆点识别。图标表示记录状态，浅底表示正在查看的日期。
